# VS Code Keyboard Shortcuts - Windows & Mac

Complete reference guide for Visual Studio Code default keyboard shortcuts.

---

## General

| Action | Windows/Linux | Mac |
|--------|---------------|-----|
| Show Command Palette | `Ctrl + Shift + P` / `F1` | `Cmd + Shift + P` / `F1` |
| Quick Open (Go to File) | `Ctrl + P` | `Cmd + P` |
| New Window | `Ctrl + Shift + N` | `Cmd + Shift + N` |
| Close Window | `Ctrl + Shift + W` | `Cmd + Shift + W` |
| Open User Settings | `Ctrl + ,` | `Cmd + ,` |
| Open Keyboard Shortcuts | `Ctrl + K` `Ctrl + S` | `Cmd + K` `Cmd + S` |
| Open Settings (JSON) | `Ctrl + Shift + P` then type `Open User Settings JSON` | `Cmd + Shift + P` then type `Open User Settings JSON` |
| Open Keyboard Shortcuts JSON | `Ctrl + K` `Ctrl + S` then click icon | `Cmd + K` `Cmd + S` then click icon |

## Tips

- **Chord shortcuts**: `Ctrl + K` means press `Ctrl+K`, release, then press the next key.
- **Customize shortcuts**: Open `File > Preferences > Keyboard Shortcuts` (or `Ctrl+K Ctrl+S` / `Cmd+K Cmd+S`).
- **Search shortcuts**: Use the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) and type "Keyboard Shortcuts".
- **Keybindings JSON**: You can edit `keybindings.json` directly for advanced customization.
